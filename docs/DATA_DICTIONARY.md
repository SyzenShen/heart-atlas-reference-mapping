## Selected analysis keys

- **donor_key = `donor`** (14 unique donors, 0 missing)
- **batch_key = `donor`** — each donor is treated as its own batch. The subsampled atlas aggregates multiple studies/assays but donor is the biological unit being held out; donor as batch matches the scvi-tools heart-atlas usage and prevents any same-donor cells appearing on both sides.
- **cell_type_key = `cell_type`** — author-provided biological annotation (not Leiden cluster IDs). 11 classes:

  - `Ventricular_Cardiomyocyte`: 5,307
  - `Endothelial`: 4,109
  - `Pericytes`: 3,204
  - `Fibroblast`: 2,446
  - `Atrial_Cardiomyocyte`: 1,009
  - `Myeloid`: 957
  - `Lymphoid`: 653
  - `Smooth_muscle_cells`: 641
  - `Neuronal`: 153
  - `Adipocytes`: 145
  - `Mesothelial`: 17

- **counts_layer = `counts`** — raw UMI counts validated at `layers['counts']` (non-negative, max sampled deviation from integer 0.00e+00). `adata.X` also holds raw counts in this loader, but the explicit `counts` layer is passed to scVI via `layer='counts'`.
